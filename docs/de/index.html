Memory mit sechs fröhlichen Bilderwelten.

OJ Memory ist ein einfaches, farbenfrohes Memoryspiel für Kinder von 3–9 Jahren auf iPhone, iPad und Apple TV. Wähle Fahrzeuge, Weltraum, Sport, Tiere, Essen oder Kuscheltiere. Es ist kein Konto nötig; Bestenlisten werden nur auf dem Gerät gespeichert.
