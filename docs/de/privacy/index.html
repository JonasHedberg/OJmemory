Deine Privatsphäre in OJ Memory

OJ Memory erhebt keine personenbezogenen Daten und sendet keine an den Entwickler. Spielergebnisse für Bestenlisten werden nur lokal auf dem Gerät gespeichert.

Keine Konten, keine Werbung, keine Drittanbieter-Analyse und kein Tracking.

So funktioniert die App

OJ Memory erhebt keine personenbezogenen Daten und sendet keine an den Entwickler. Spielergebnisse für Bestenlisten werden nur lokal auf dem Gerät gespeichert.

Lokale Speicherung

Lösche die App und ihre Daten vom Gerät, um lokal gespeicherte Spieldaten zu entfernen.

Drittanbieter

OJ Memory enthält keine Werbung, keine Drittanbieter-Analyse, keine Tracking-SDKs und keine vom Entwickler betriebenen Server für Spieldaten.

Datenschutz von Kindern

GitHub Issues sind öffentlich. Supportanfragen sollten von einer erwachsenen Person erstellt werden; persönliche oder andere sensible Daten dürfen nicht veröffentlicht werden.
