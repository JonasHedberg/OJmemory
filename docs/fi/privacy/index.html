Yksityisyytesi OJ Memoryssa

OJ Memory ei kerää eikä lähetä henkilötietoja kehittäjälle. Ennätyslistan pelitulokset tallennetaan vain paikallisesti laitteelle.

Ei tilejä, ei mainoksia, ei kolmannen osapuolen analytiikkaa eikä seurantaa.

Miten sovellus toimii

OJ Memory ei kerää eikä lähetä henkilötietoja kehittäjälle. Ennätyslistan pelitulokset tallennetaan vain paikallisesti laitteelle.

Paikallinen tallennus

Poista sovellus ja sen tiedot laitteelta, jotta paikallisesti tallennetut pelitiedot poistuvat.

Kolmannet osapuolet

OJ Memory ei sisällä mainontaa, kolmannen osapuolen analytiikkaa, seuranta-SDK:ita eikä kehittäjän ylläpitämiä palvelimia pelitiedoille.

Lasten yksityisyys

GitHub Issues on julkinen. Aikuisen tulee luoda tukipyyntö, eikä henkilötietoja tai muita arkaluonteisia tietoja pidä julkaista.
