Tietosuojavalintasi

OJ Memoryssa ei ole kehittäjän ylläpitämiä tilejä tai palvelimelle tallennettuja käyttäjätietoja. Tärkeimmät valinnat koskevat laitteen paikallisia tietoja.

Paikallinen tallennus

Poista sovellus ja sen tiedot laitteelta, jotta paikallisesti tallennetut pelitiedot poistuvat.

Kolmannet osapuolet

Kehittäjän ylläpitämää tiliä tai palvelinprofiilia ei ole vietäväksi, muokattavaksi tai poistettavaksi.

Yhteystiedot

GitHub Issues on julkinen. Aikuisen tulee luoda tukipyyntö, eikä henkilötietoja tai muita arkaluonteisia tietoja pidä julkaista.
