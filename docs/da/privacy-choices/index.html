Dine privatlivsvalg

OJ Memory har ingen udviklerejede konti eller brugerdata gemt på en server. Dine vigtigste valg gælder lokale data på enheden.

Lokal lagring

Slet appen og dens data fra enheden for at fjerne lokalt gemte spildata.

Tredjeparter

Der findes ingen udviklerkonto eller serverprofil, som kan eksporteres, ændres eller slettes.

Kontakt

GitHub Issues er offentlige. En voksen bør oprette supportsager, og personlige eller andre følsomme oplysninger må ikke offentliggøres.
