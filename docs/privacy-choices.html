Integritetsval

OJ Memory skickar inte personuppgifter eller speldata till utvecklaren. Därför finns inga serverlagrade användaruppgifter att visa, exportera eller radera.

Din kontroll: spelresultat ligger lokalt på enheten. Om du vill ta bort all lokal OJ Memory-data kan du radera appen och dess data från enheten.

Spårning och annonser

Appen använder inte spårning, tredjepartsannonser eller tredjepartsanalys. Det finns därför inga spårnings- eller annonsval att hantera.

Frågor

Om du har en integritetsfråga kan du skapa ett ärende via GitHub Issues. GitHub Issues är offentliga, så skriv inte personuppgifter eller annan känslig information i ärendet.
