La tua privacy in OJ Memory

La tua privacy in OJ Memory

OJ Memory non raccoglie né invia dati personali allo sviluppatore. I risultati delle classifiche vengono memorizzati solo localmente sul dispositivo.

Nessun account, nessuna pubblicità, nessuna analisi di terze parti e nessun tracciamento.

Come funziona l’app

OJ Memory non raccoglie né invia dati personali allo sviluppatore. I risultati delle classifiche vengono memorizzati solo localmente sul dispositivo.

Archiviazione locale

Elimina l’app e i relativi dati dal dispositivo per rimuovere i dati di gioco salvati localmente.

Terze parti

OJ Memory non include pubblicità, analisi di terze parti, SDK di tracciamento o server gestiti dallo sviluppatore per i dati di gioco.

Privacy dei bambini

GitHub Issues è pubblico. Un adulto dovrebbe creare le richieste di supporto e non devono essere pubblicate informazioni personali o altri dati sensibili.
