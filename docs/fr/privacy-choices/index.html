Vos choix de confidentialité

OJ Memory ne possède aucun compte géré par le développeur ni aucune donnée utilisateur stockée sur serveur. Vos principaux choix concernent les données locales de l’appareil.

Stockage local

Supprimez l’app et ses données de l’appareil pour effacer les données de jeu stockées localement.

Tiers

Il n’existe aucun compte géré par le développeur ni profil côté serveur à exporter, modifier ou supprimer.

Contact

GitHub Issues est public. Un adulte doit créer les demandes d’assistance et aucune information personnelle ou sensible ne doit y être publiée.
