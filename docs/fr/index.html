Un jeu de mémoire dans six univers d’images joyeux.

OJ Memory est un jeu de mémoire simple et coloré pour les enfants de 3 à 9 ans sur iPhone, iPad et Apple TV. Choisissez Véhicules, Espace, Sport, Animaux, Nourriture ou Peluches. Aucun compte n’est requis et les meilleurs scores restent uniquement sur l’appareil.
