Votre vie privée dans OJ Memory

OJ Memory ne collecte ni n’envoie de données personnelles au développeur. Les résultats utilisés pour les meilleurs scores sont stockés uniquement sur l’appareil.

Aucun compte, aucune publicité, aucune analyse tierce et aucun suivi.

Fonctionnement de l’app

OJ Memory ne collecte ni n’envoie de données personnelles au développeur. Les résultats utilisés pour les meilleurs scores sont stockés uniquement sur l’appareil.

Stockage local

Supprimez l’app et ses données de l’appareil pour effacer les données de jeu stockées localement.

Tiers

OJ Memory ne contient ni publicité, ni analyse tierce, ni SDK de suivi, ni serveur exploité par le développeur pour les données de jeu.

Vie privée des enfants

GitHub Issues est public. Un adulte doit créer les demandes d’assistance et aucune information personnelle ou sensible ne doit y être publiée.
