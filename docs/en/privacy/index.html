Your privacy in OJ Memory

OJ Memory does not collect or send personal data to the developer. High-score game results are stored only on the device.

No accounts, no ads, no third-party analytics, and no tracking.

How the app works

OJ Memory does not collect or send personal data to the developer. High-score game results are stored only on the device.

Local storage

Delete the app and its data from the device to remove locally stored game data.

Third parties

OJ Memory does not include advertising, third-party analytics, tracking SDKs, or developer-operated servers for game data.

Children’s privacy

GitHub Issues are public. An adult should create support issues and no personal or other sensitive information should be posted.
