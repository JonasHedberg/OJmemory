OJ Memory

Ett enkelt och färgglatt memoryspel på svenska, skapat för barn 2–5 år. Matcha glada arbetsfordon på iPhone, iPad och Apple TV.

Barn 2–5 år Svenska Ingen reklam Ingen spårning Fungerar utan konto

Tryggt och enkelt

Ingen datainsamling

Spelet skickar inte personuppgifter, speldata eller enhetsidentifierare till utvecklaren eller tredje part.

Lokala topplistor

Tid, gissningar och poäng sparas endast lokalt på enheten för att kunna visa topplistan.

För små barn

Inga konton, köp, annonser, chattar eller sociala funktioner behövs för att spela.

Information

För frågor om hur spelet hanterar information, läs integritetspolicyn. Om du behöver hjälp med appen, gå till support.
