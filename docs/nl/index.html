Memory met zes vrolijke beeldwerelden.

OJ Memory is een eenvoudig en kleurrijk memoryspel voor kinderen van 3–9 jaar op iPhone, iPad en Apple TV. Kies Voertuigen, Ruimte, Sport, Dieren, Eten of Knuffels. Er is geen account nodig en highscores worden alleen op het apparaat bewaard.
