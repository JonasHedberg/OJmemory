Jouw privacy in OJ Memory

OJ Memory verzamelt of verstuurt geen persoonsgegevens naar de ontwikkelaar. Spelresultaten voor highscores worden uitsluitend lokaal op het apparaat opgeslagen.

Geen accounts, geen advertenties, geen analyse door derden en geen tracking.

Hoe de app werkt

OJ Memory verzamelt of verstuurt geen persoonsgegevens naar de ontwikkelaar. Spelresultaten voor highscores worden uitsluitend lokaal op het apparaat opgeslagen.

Lokale opslag

Verwijder de app en de bijbehorende gegevens van het apparaat om lokaal opgeslagen spelgegevens te wissen.

Derden

OJ Memory bevat geen advertenties, analyse door derden, tracking-SDK’s of door de ontwikkelaar beheerde servers voor spelgegevens.

Privacy van kinderen

GitHub Issues is openbaar. Een volwassene moet supportvragen aanmaken en er mogen geen persoonlijke of andere gevoelige gegevens worden geplaatst.
