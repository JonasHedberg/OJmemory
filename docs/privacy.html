Integritetspolicy

OJ Memory är utformat för barn 2–5 år och använder en integritetsvänlig modell där spelet inte samlar in eller skickar personuppgifter till utvecklaren.

Senast uppdaterad: 26 augusti 2026

Kort sammanfattning: OJ Memory har inga användarkonton, ingen reklam, ingen tredjepartsanalys, ingen spårning och ingen server som tar emot speldata.

1. Vilken information behandlas i appen?

När ett spel avslutas kan OJ Memory spara följande uppgifter lokalt på enheten för topplistan:

  • antal kort i spelet,
  • antal gissningar,
  • speltid,
  • poäng,
  • datum för resultatet.

Dessa uppgifter är spelresultat. De lagras i appens lokala lagring på användarens enhet och överförs inte till utvecklaren.

2. Uppgifter som inte samlas in

OJ Memory samlar inte in eller överför namn, e-postadress, telefonnummer, fysisk adress, platsdata, kontakter, foton, ljud, annonseringsidentifierare, enhetsidentifierare, användarprofiler eller annan personligt identifierbar information.

Appen använder inte tredjepartsannonsering, tredjepartsanalys eller spårning mellan appar och webbplatser.

3. Barns integritet

OJ Memory är avsett för små barn. Appen ber inte barnet att lämna personuppgifter och innehåller inga konton, chattfunktioner, sociala nätverk eller formulär för personuppgifter. Ingen personligt identifierbar information eller enhetsinformation skickas till tredje part av appen.

4. Lagring och radering

Topplistan sparas lokalt på enheten så länge appens lokala data finns kvar. Utvecklaren har ingen åtkomst till dessa uppgifter och kan därför inte läsa eller radera dem på distans. Lokal speldata tas bort när appens data raderas från enheten, exempelvis genom att appen raderas, med förbehåll för eventuell säkerhetskopiering och återställning som hanteras av Apple enligt användarens enhets- och iCloud-inställningar.

5. Samtycke och integritetsval

Eftersom appen inte överför personuppgifter till utvecklaren behövs inget samtycke för sådan datainsamling. Det finns inga serverlagrade användaruppgifter att exportera, korrigera eller radera. Läs även sidan Integritetsval.

6. Tredje parter

Appen innehåller enligt den aktuella versionen inga tredjeparts-SDK:er för annonsering, analys eller spårning. Apple tillhandahåller operativsystemet, App Store-distribution och eventuella systemtjänster. Uppgifter som Apple själv behandlar omfattas av Apples egna villkor och integritetspolicy och är inte uppgifter som OJ Memory-utvecklaren samlar in genom appen.

7. Webbplatsen

Den här webbplatsen är avsedd att ligga på GitHub Pages. Webbplatsen innehåller ingen egen analyskod, reklam eller spårningskod. GitHub kan som webbhotell behandla teknisk information om besök enligt GitHubs egna villkor och integritetspolicy.

8. Ändringar

Om appens databehandling ändras kommer denna policy och uppgifterna i App Store Connect att uppdateras innan eller i samband med att ändringen görs tillgänglig för användare.
