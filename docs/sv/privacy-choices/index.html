Hantera din lokala data

OJ Memory har inga konton eller utvecklarservrar med användardata. De enda sparade speluppgifterna finns lokalt på enheten.

Vad kan jag radera?

Appens topplistor innehåller lokalt sparade spelresultat: antal kort, gissningar, tid, poäng och datum.

Radera appdata

För att ta bort OJ Memory och dess lokala data använder du enhetens funktion för att radera appen. Att avlasta appen kan bevara dokument och data och är därför inte samma sak.

Data hos utvecklaren

Den verifierade appversionen skickar ingen spel- eller persondata till utvecklaren. Det finns därför ingen serverlagrad OJ Memory-profil att begära åtkomst till, exportera eller radera.

Frågor

En vuxen kan skapa ett offentligt GitHub Issue. Inkludera inte personuppgifter.
