Memory med sex glada bildvärldar.

OJ Memory är ett enkelt och färgglatt memoryspel för barn 3–9 år på iPhone, iPad och Apple TV. Välj Fordon, Rymden, Sport, Djur, Mat eller Gosedjur. Spelet fungerar utan konto och sparar bara topplistan lokalt på enheten.
