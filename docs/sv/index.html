Memory med glada fordon.

OJ Memory är ett enkelt och färgglatt memoryspel för barn 2–5 år på iPhone och iPad. Spelet fungerar utan konto och sparar bara topplistan lokalt på enheten.

Byggt för ett avskalat barnläge

Appens nuvarande version innehåller inga externa tjänster för annonsering, analys eller användarkonton.

🛡️

Integritet först

Spelresultat används för topplistor och sparas lokalt. De skickas inte till utvecklaren.

🚫

Utan reklam

Ingen tredjepartsannonsering, ingen beteendeprofilering och ingen spårning mellan appar eller webbplatser.

Support via GitHub Issues
