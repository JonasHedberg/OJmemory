Vanliga frågor

Var sparas topplistan?

Topplistan sparas lokalt i appens lagring på enheten och skickas inte av appen till utvecklaren.

Hur raderar jag topplistan och appens lokala data?

Radera OJ Memory och dess data från enheten. Att endast avlasta appen kan bevara dokument och data.

Behöver jag ett konto?

Nej. OJ Memory har ingen inloggning och inga användarkonton.

Finns reklam, köp eller spårning?

Nej, inte i den verifierade versionen. Appen innehåller ingen reklam, inga köp i appen, ingen tredjepartsanalys och ingen spårning.

Vad ska jag skriva i ett supportärende?

Ta gärna med enhetsmodell, iOS/iPadOS-version, appversion, tydliga steg för att återskapa problemet och en skärmbild om den inte innehåller privata uppgifter.
