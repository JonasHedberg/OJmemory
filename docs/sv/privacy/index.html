Din integritet i OJ Memory

OJ Memory är utformat för barn 2–5 år och använder en integritetsvänlig modell där appen inte samlar in eller skickar personuppgifter till utvecklaren.

Kort sammanfattning: inga konton, ingen reklam, ingen tredjepartsanalys och ingen spårning. Spelresultat för topplistan lagras lokalt på enheten.

1. Om policyn

Denna integritetspolicy gäller appen OJ Memory för iPhone och iPad. Ansvarig utvecklare är Jonas Hedberg. Policyn beskriver den version av appen vars källkod verifierades den 30 augusti 2026.

2. Uppgifter som behandlas lokalt

När ett spel avslutas kan OJ Memory spara antal kort, antal gissningar, speltid, poäng och datum för att visa lokala topplistor. Informationen lagras i appens lokala lagring på enheten. Den överförs inte av appen till utvecklaren eller till någon egen server.

3. Uppgifter som appen inte samlar in

OJ Memory samlar inte in eller överför namn, e-postadress, telefonnummer, fysisk adress, platsdata, kontakter, foton, ljud, annonseringsidentifierare, enhetsidentifierare, användarprofiler eller annan personligt identifierbar information. Appen har inga användarkonton.

4. Ändamål

Den lokala spelinformationen används endast för appens egen funktion: att beräkna resultat och visa topplistor på den aktuella enheten.

5. Delning med tredje part

Appen delar inte användardata med tredje part och innehåller i den verifierade versionen inga tredjeparts-SDK:er för annonsering, analys eller spårning. Eftersom appen inte överför användardata finns ingen extern mottagare av appens lokala spelresultat.

Apple tillhandahåller operativsystemet och App Store-distributionen. Uppgifter som Apple själv behandlar i sina egna tjänster omfattas av Apples villkor och integritetspolicy och är inte data som OJ Memory skickar till utvecklaren.

6. Barns integritet

OJ Memory är avsett för barn 2–5 år. Appen ber inte barnet att lämna personuppgifter och innehåller inga konton, chattfunktioner, sociala nätverk, reklam, köp i appen eller formulär för personuppgifter.

7. Lagring och radering

Topplistan finns kvar så länge appens lokala data finns kvar på enheten. Lokal speldata kan tas bort genom att radera appen och dess data från enheten. Att endast avlasta en app kan bevara dokument och data, så använd funktionen för att radera appen om all lokal appdata ska tas bort.

Eventuell enhetsbackup eller återställning som tillhandahålls av Apple styrs av användarens Apple- och iCloud-inställningar.

8. Samtycke och integritetsval

OJ Memory begär inget samtycke till datainsamling eftersom den verifierade versionen inte samlar in data från appen. Det finns därför inget utvecklarägt konto eller serverlagrad användardata att exportera, ändra eller radera. Se Integritetsval för praktiska instruktioner om lokal data.

9. Webbplats och GitHub Issues

Den här supportsidan är en statisk GitHub Pages-webbplats utan egen annonsering, analyskod eller egna cookies. GitHub kan som plattformsleverantör behandla tekniska uppgifter när webbplatsen eller GitHub Issues används enligt GitHubs egna villkor och integritetspolicy.

GitHub Issues är en offentlig supportkanal. Publicera aldrig barns personuppgifter, kontaktuppgifter, kontouppgifter eller annan känslig information i ett ärende.

10. Ändringar

Om appens databehandling ändras ska denna policy och uppgifterna i App Store Connect uppdateras så att de fortsatt beskriver den faktiska versionen av appen.

11. Kontakt om integritet

Integritetsfrågor hanteras via projektets GitHub Issues. En vuxen bör skapa ärendet och formulera frågan utan personuppgifter.
