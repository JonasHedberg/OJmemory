Information om appen

Grundläggande juridisk och distributionsrelaterad information för OJ Memory.

Utvecklare och rättigheter

OJ Memory utvecklas av Jonas Hedberg. Appens namn, grafik och övrigt material får endast användas i den utsträckning som tillämplig licens eller lag medger.

App Store-distribution

OJ Memory distribueras via Apples App Store och användningen omfattas även av tillämpliga villkor för App Store och Apples standardvillkor för licensierade appar när inget separat anpassat licensavtal anges i App Store Connect.

Ingen rådgivning eller kritisk tjänst

OJ Memory är ett enkelt underhållningsspel och ska inte användas som säkerhetskritisk, medicinsk eller annan professionell tjänst.

Kontakt

Frågor om appen hanteras via projektets GitHub Issues. Ärenden är offentliga och ska inte innehålla personuppgifter eller annan känslig information.
