Tillgänglighetsstöd

OJ Memory använder Apples inbyggda tillgänglighetsfunktioner där de är relevanta för spelet.

VoiceOver och tydliga etiketter

Interaktiva kontroller har tillgänglighetsetiketter. Ett nedvänt kort avslöjar inte fordonets identitet i sin etikett innan kortet har vänts.

Minska rörelse

Appen läser systeminställningen Minska rörelse. Kortanimationer och splashpresentation anpassas när inställningen är aktiverad.

Rapportera ett tillgänglighetsproblem

Beskriv problemet via GitHub Issues. Ta gärna med enhet, systemversion och vilken tillgänglighetsfunktion som används, men publicera inga personuppgifter.
