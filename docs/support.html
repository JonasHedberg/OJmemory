Support

Hjälp med OJ Memory

Support och felrapporter hanteras öppet via GitHub Issues.

GitHub Issues

Om något inte fungerar som förväntat, eller om du har ett förslag på förbättring, skapa ett nytt ärende i projektets GitHub Issues.

Öppna GitHub Issues

Viktigt: GitHub Issues är offentliga. Lägg inte in personuppgifter, barns uppgifter, lösenord eller annan känslig information i ett ärende.

Innan du skapar ett ärende

  • Kontrollera gärna om samma problem redan finns rapporterat.
  • Beskriv vilken enhet du använder: iPhone, iPad eller Apple TV.
  • Ange iOS, iPadOS eller tvOS-version om du känner till den.
  • Beskriv kort vad som hände och vad du förväntade dig skulle hända.
