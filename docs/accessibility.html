Tillgänglighet

OJ Memory är utformat med tydliga kontroller, stora visuella element och stöd för flera av Apples tillgänglighetsfunktioner.

  • VoiceOver-etiketter för spelkort och centrala kontroller.
  • Stöd för inställningen Minska rörelse (Reduce Motion), med enklare övergång i stället för 3D-kortvändning.
  • Tydlig fokusmarkering och fjärrkontrollsnavigering på Apple TV.
  • Responsiv layout för olika skärmstorlekar på iPhone och iPad.

Om du stöter på ett tillgänglighetsproblem, kontakta {{SUPPORT_EMAIL}} via supportsidan.
