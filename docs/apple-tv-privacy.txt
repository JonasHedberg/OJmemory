OJ Memory – Integritetspolicy för Apple TV
Senast uppdaterad: 26 augusti 2026

OJ Memory är utformat för barn 2–5 år. Appen samlar inte in eller överför personuppgifter, speldata eller enhetsidentifierare till utvecklaren eller tredje part.

Appen har inga användarkonton, ingen reklam, ingen tredjepartsanalys och ingen spårning.

När ett spel avslutas kan OJ Memory spara antal kort, antal gissningar, speltid, poäng och datum lokalt på Apple TV-enheten för att visa en lokal topplista. Dessa uppgifter lämnar inte enheten och utvecklaren har inte åtkomst till dem.

Lokal speldata finns kvar så länge appens lokala data finns kvar och kan tas bort genom att radera appen och dess data, med förbehåll för eventuell säkerhetskopiering/återställning som hanteras av Apple enligt användarens inställningar.

OJ Memory skickar inte namn, e-postadress, plats, bilder, ljud, kontakter, annonseringsidentifierare, enhetsidentifierare eller annan personligt identifierbar information till utvecklaren eller tredje part.

Appen innehåller inga tredjeparts-SDK:er för annonsering, analys eller spårning i den aktuella versionen.
